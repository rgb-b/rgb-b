signal-tui

rust   ratatui   signal-cli   WIP

A keyboard-driven terminal UI for Signal messenger, backed by signal-cli over JSON-RPC.

Originally built in Python with Textual, it's being rebuilt in Rust with ratatui for a faster, leaner, buddy-list-style interface. The Python version still lives in the archive but is no longer maintained.
