Colour-match is a tool I created to help assist with colour matching, speeding up the process and removing human error. The program creates a calibration chart for the user to scan with a Spectrodensitometer, which is connected to the PC via xrite's DataCatcher program.

The program compares the LAB reading between the target colour, and the current scanned colour. It uses the calibration chart to calculate how far off from standard LAB->CMYK conversion your printer is, and use that value to compensate your CMYK formula values for you.
