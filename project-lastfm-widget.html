lastfm-widget

python   pywebview   react

A compact always-on-top desktop widget (300×100px) that shows what's currently playing from Last.fm.

It polls user.getRecentTracks every 15 seconds and renders an HTML/CSS/React UI through pywebview (WebKitGTK on Linux). No backend, no database, no build step — just a config file with a username and API key.
