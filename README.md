# rgb-b.com

El's personal portfolio and blog. Old-web aesthetic, monochrome with a single accent colour.

Live at **[rgb-b.com](https://rgb-b.com)** (Cloudflare Pages).

## Quick start

```bash
python3 -m http.server 8000
# Visit http://localhost:8000
```

No build step. Push to `main` to deploy.

## Tech

Pure HTML5/CSS3/JS, no build step. One stylesheet (`style.css`) — colours are
CSS custom properties at the top, so recolour the whole site by editing those
variables rather than swapping stylesheets.
