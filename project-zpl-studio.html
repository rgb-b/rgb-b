zpl studio

rust   egui   android   WIP

A Dymo-style WYSIWYG label designer for Zebra printers. You design labels visually on a canvas and the ZPL is generated at print time — no hand-writing raw ZPL.

Built as a Rust + egui desktop app with an Android build alongside it. Image elements and a clipart library have shipped; batch print, .zlabel save/load, barcode and shape elements, and undo/redo are in progress. GitHub Actions builds Windows EXE, Linux AppImage, and an Android APK on every push.
